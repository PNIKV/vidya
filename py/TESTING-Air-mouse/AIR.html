🔌 Hardware Wiring & CS Pin Fix Guide

CRITICAL HARDWARE FIX FOR GY-6500 / GY-9250 MODULES:
On GY-6500 and GY-9250 breakout boards, the CS (Chip Select) / NCS pin selects between SPI and I2C modes. If left floating or tied to GND, the chip locks into SPI mode and ignores all I2C signals, returning scan_complete count: 0!
MPU/ICM Module Pin ESP32 DevKit V1 Pin Function / Required State
VCC 3.3V Power Input (3.3V)
GND GND Ground Connection
SDA GPIO 21 I2C Serial Data (Internal Pull-Up enabled)
SCL GPIO 22 I2C Serial Clock (Internal Pull-Up enabled)
CS / NCS 3.3V (or GPIO 5) MUST BE PULLED HIGH TO FORCE I2C MODE
AD0 GND (0x68) / 3.3V (0x69) I2C Address Selection
