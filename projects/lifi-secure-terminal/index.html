💡 Hardware Calibration Quick Guide:
  • Potentiometer Adjustment: Rotate the blue screw on your LDR module until the DO LED lights up ONLY when torch/screen flash hits the sensor.
  • Ambient Light Shielding: Use a small black tube or cardboard shroud around the LDR to prevent room light noise.
  • Auto-Baud Feature: Firmware v2.0 auto-measures the Start Bit pulse to synchronize bit timing automatically!
Android Native APK Project Camera2 Hardware Torch API

The web browser's Torch API is restricted on many devices. The native Android APK uses CameraManager.setTorchMode() — the same call used by system flashlight apps — giving you 100% reliable direct hardware flash control with zero browser restrictions.

1
Install Android Studio (free) from developer.android.com/studio. It includes the Android SDK and Gradle build tools automatically.
2
Open the APK project folder in Android Studio: File → Open → android_apk/ (inside the lifi-secure-terminal project folder). Android Studio will auto-sync Gradle on first open.
3
Connect your Android phone via USB cable. Enable Developer Options → USB Debugging on your phone (tap Build Number 7 times in Settings → About Phone).
4
Build & Run: Click the green ▶ Run button in Android Studio (or press Shift + F10). Select your device from the list. The APK is installed and launched instantly.
5
Generate signed APK file to share: Build → Generate Signed Bundle / APK → APK → Release. The output APK will be in app/release/app-release.apk.
