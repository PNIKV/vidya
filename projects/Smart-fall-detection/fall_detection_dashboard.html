Where this goes next

Built to grow into a full safety platform

This build proves the core detection loop — accelerometer signature in, alert out. The roadmap below is what turns it from a working prototype into something a caregiver could actually rely on.

GPS + GSM module

Add a SIM800L/NEO-6M pair so a confirmed fall sends an SMS with live coordinates straight to a caregiver — no phone or WiFi required.

Hardware

Heart-rate & SpO2 fusion

Pair a MAX30102 sensor so an alert also reports whether vitals stayed stable through the fall — cutting false-alarm severity, not just count.

Sensor fusion

On-device ML classifier

Replace fixed g-thresholds with a lightweight TinyML model trained on real fall vs. sit-down vs. drop-and-catch data, cutting false positives further.

Firmware

Companion app

A phone app for the caregiver: push notifications, fall history, battery status, and one-tap "call now" — the dashboard's job, mobile-first.

Software

Auto-calibrating orientation

Use the gyroscope to auto-detect whether the device is worn on the neck, waist, or wrist and adjust axis mapping and thresholds — no manual button needed.

Firmware

Cloud history & analytics

Log every event to a small backend (Firebase/Supabase) so families and clinicians can spot patterns — time of day, frequency, recovery time — over months.
